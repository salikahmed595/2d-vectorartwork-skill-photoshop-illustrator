# Artwork brief - cat-pfp v6 "Moonlit Cat Mage" (revision of v5)

| Item | Value |
|---|---|
| Subject / identity to preserve | The user's ginger tabby: green eyes, white muzzle and chest, pink nose, tabby stripes |
| Use and size (px, ppi, colour mode) | Profile picture; 2000×2000 master, 1080 webp; RGB, 72 ppi |
| Style (flat / cel / gradient / semi-real) | Anime cel-shaded vector with Photoshop light passes |
| Viewpoint and pose | Front, head tilted 4°; right paw raised, holding a floating rune orb |
| Palette (5-8 hex) and mood | #f39a4c ginger, #fff3e2 cream, #232d6a navy, #e6b65c gold, #6ff6ff cyan, #7346b8 wisteria. Calm, magical night |
| Scene layers (far / mid / near) and props | Far: sky, stars, moon, castles. Mid: blossom trees, rune circle. Near: wisteria, particles. Props: amulet, orb |
| Text (exact) | None |
| Required source files | .ai, .svg, .psd (one layer per part), PNG/JPG/WebP, parts/ |
| Must not change | Identity, pose, palette, composition of v5 |
| Acceptance criteria | 12-point audit PASS or ACCEPTED-WITH-NOTE, with no open P0/P1; face is the brightest area; reads in a 64 px circle; no AI generation |

Light plan:
- Key light: soft warm, from the upper left.
- Magic fill: cyan, from the orb (lower left) and the amulet.
- Rim: cool moonlight from the upper right.

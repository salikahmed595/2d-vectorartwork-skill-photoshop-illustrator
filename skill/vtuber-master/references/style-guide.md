# Reference-based art direction

## Reference cluster A — blonde cat-ear character (images 1–4)
- Long warm-gold hair with sharply differentiated strand families and glints; pale ears with pink inner fur; oversized vibrant green irises and fine multilayer highlights.
- Golden knitted off-shoulder garment, charcoal/green jacket and blue-gray skirt, expressive hand gestures and lively facial changes.
- Art direction: clean 2D cel-shading blended with subtle gradients, delicate linework, coherent saturated-but-controlled palette.
- Preserve likeness across face close-up, full-body, wink and hand-heart only when working on that same character with adequate rights.

## Reference cluster B — lineup and black-haired character (images 5–7)
- Production-art polish, dynamic fabric material boundaries, glossy dark hair, detailed colored eye reflections, high-frequency costume details.
- Distinguish *lighting change* from *character identity change* in day/night variants.
- Reference lineup shows multiple independent character identities; do not mix their traits into one accidentally.

## Reference cluster C — silver-haired 3D-looking character (images 8–9)
- Complex garment design with layered buckles, plaid, gloves, sleeves, chains, decals, boots; polished physically plausible material responses.
- These appear 3D-rendered, not proof they are Live2D models. 2D recreation requires an explicit stylization pass.

## Anti-patterns
- Single flat PNG misrepresented as Live2D-ready PSD.
- Flat segmentation masks that lose concealed eye/neck/arm surfaces.
- Unstable costume hardware, different numbers of fingers, face-shape drift, messy hair silhouettes.
- Overcomplicated posing for the base rig sheet; rig from an animation-friendly neutral pose, then build pose art separately.
- Copying reference image watermarks or logos or claiming third-party art as original.
